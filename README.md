# 💰 Nikel

Projeto desenvolvido durante meus estudos de **desenvolvimento web**, utilizando conteúdos do curso da **Growdev**.

O objetivo do projeto foi praticar conceitos fundamentais de desenvolvimento frontend através da criação de uma aplicação para organização e acompanhamento de informações financeiras.

---

## 📌 Sobre o projeto

O Nikel foi desenvolvido como uma atividade prática de aprendizado, permitindo colocar em prática conceitos básicos de desenvolvimento web.

Durante o projeto, foram trabalhados conceitos como:

* Estruturação de páginas;
* Criação de interfaces;
* Estilização com CSS;
* Programação com JavaScript;
* Manipulação de elementos da página;
* Organização de arquivos;
* Utilização do Git e GitHub.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

---

## 🎯 Objetivo

O principal objetivo deste projeto foi **praticar e consolidar conhecimentos iniciais em desenvolvimento web**, transformando os conteúdos estudados em uma aplicação funcional.

Este projeto faz parte da minha trajetória de aprendizado e representa uma das etapas iniciais da minha experiência com desenvolvimento de software.

---

## 📚 Origem

Projeto desenvolvido como parte dos estudos realizados através do curso da **Growdev**.
